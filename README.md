Ventspils Augstskolas diplomdarbu LaTeX šablons
===============================================

Šis ir neoficiāls šablons, ko radījis Jānis Šmēdiņš un pakāpeniski attīstījis
to studiju laikā. Šis Git repozitorijs apvieno LaTeX kodu, ko autors
izmantojis bakalaura un maģistra darbiem, ar (daļēji) izņemtu oriģinālo saturu,
lai kopīgotu ar citiem interesentiem -- VeA studentiem.

Lietošana
---------

Nokompilēt LaTeX kodu uz PDF var izmantojot:

    make

Tehniski, var arī ar

    xelatex diplomdarbs.tex

bet `make` papildus veic SVG uz PDF konversiju attēliem, kas lietoti šablonā.

Vēlies izmantot šablonu? Nokopē un modificē!
